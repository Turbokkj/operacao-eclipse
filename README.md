# Operação Eclipse

Projeto de jogo criado em Godot 4.3, com exportação prevista para Web e um serviço separado de matchmaking/relay por WebSocket.

Este repositório foi reservado para o projeto, mas o código-fonte completo ainda não foi enviado. O pacote de distribuição saneado foi preparado separadamente; ele exclui o relatório interno de testes e os recursos binários gerados, que podem ser recriados pelos scripts do projeto.

A publicação web só poderá ser concluída depois que o código-fonte estiver no repositório e a exportação Godot/Web for validada. O servidor multiplayer também requer hospedagem persistente fora da Vercel.
